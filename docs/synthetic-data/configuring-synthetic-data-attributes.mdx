# Configuring Synthetic Data Attributes

To configure the Synthetic Data Generator, follow these steps:

1. **Navigate to Your Database**: Log in to your Rocket account and select the desired database from the database selector in the top-left corner of the interface.

2. **Access the Synthetic Data Page**: Click on the "Synthetic Data" link in the left navigation menu to go to the Synthetic Data page.

3. **Select the Desired Table**: Choose the table where you want to configure the Synthetic Data Generator from the list of tables. Click on the table to open it.

4. **Pick the Attribute to Set**: Select the attribute in the table that you want to configure for the Synthetic Data Generator. Click the "Edit" button next to the attribute.

5. **Set the Synthetic Data Generator**: You will be directed to the Set Synthetic Generator page. Configure the data generator according to your needs.

6. **Click on Submit**: After configuring the data fields, click the "Update" button to save your changes.

Repeat these steps for all attributes as needed.
